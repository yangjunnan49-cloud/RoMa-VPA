# Evaluation

This directory will contain the unified evaluation and aggregation scripts used to reproduce Tables 1–4.

Planned outputs:

- Table 1: FMR, IR, and registration recall under the unified preprocessing protocol;
- Table 2: conditional RRE/RTE on each method's successfully registered subset;
- Table 3: ablation results with the configuration-to-checkpoint mapping;
- Table 4: runtime and peak-memory summaries for the documented profiling subset.

The scripts will report both per-pair outputs and aggregate values. For Table 2, the success subset will remain explicit so conditional errors are not interpreted as measurements on an identical sample set across methods.
